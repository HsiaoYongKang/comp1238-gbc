## Week 1 - History
- 5,000 years ago in Mesopotamia, Uruk, cuneiform: wedge-shaped marks on clay tablets.
- Babylonian Numerals: base-60 system.
## Week 2 - Bits and Bytes
- Byte: Group of 8 bits.
- Non-Volatile Memory: Keeps data without power (e.g., SSD, HDD).
## Week 3 - Text Structure
- UTF-8 is the most popular encoding on the internet.
- GitHub is a platform for version control and collaboration.
- Markdown is used for documentation (README.md).
## Week 4 - Keyboards and Editors
- Keyboard layouts: QWERTY, AZERTY, Dvorak.
- Microsoft Word is a word processor.
## Week 5 - CLI
- Modern CLI is efficient for remote work with low bandwidth requirements.
- SSH (Secure Shell) can connect to remote computers securely. Allows command line access to remote systems.
